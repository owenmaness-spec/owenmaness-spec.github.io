An introduction to VIM

How to install vim on your computer(this is the easy part)

  1. Open the Terminal app on your Mac.
  2. Type vim into your terminal to start the vim editor.
  3. Then type :q to exit (press Esc before :q)

Helpful vim tips and tricks

  • Vim can be customized, for example, you can do the command :syntax on to get colors for each command
  • To permanently get syntax on as well as some other helpful features, you can use this code 
                        syntax enable
                   
                   filetype indent on
                " set autoindent width to 4 spaces (see
                " http://www.vim.org/tips/tip.php?tip_id=83)
                set et
                set sw=4
                set smarttab

                set background=dark
                colorscheme desert

                set columns=80
                set colorcolumn=80
                set nowrap

                set number
  • You can use o to add a line directly below the line you are working on
  • You can use Shift + O to add a line directly above the line you are working on
  • The most important thing is the save your work, when you want to save a change use the command :wq instead
  • Add, commit, and push make up the most important part of vim, adding your code, onto your awesome website! For example you could use git add index.htiml, git commit -m "this is an example(be specific here)", and git push if you use all these correctly, your code should populate into your website within a few minutes
  • To check your website without doing add, commit, and push, use open index.html (index.html is my file name, yours may be different)
